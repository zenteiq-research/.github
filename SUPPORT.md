# Getting help

Thank you for using ZenteiQ Research software. Here is where to go, depending on what you need.

| You want to... | Go to |
| :--- | :--- |
| Learn how to use ScireX | The documentation at [scirex.org](https://scirex.org) |
| Ask a usage question or share an idea | **Discussions** in the relevant repository, where enabled |
| Report a bug or an incorrect numerical result | **Issues** in the relevant repository, using the bug report form |
| Request a feature, method or benchmark | **Issues** in the relevant repository, using the feature request form |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Raise a conduct concern | As described in the [Code of Conduct](CODE_OF_CONDUCT.md) |
| Discuss enterprise use, research partnerships or technical briefs | Contact ZenteiQ through [zenteiq.ai](https://zenteiq.ai) or at info@zenteiq.ai |

## Before you ask

- Search existing issues and discussions, as your question may already be answered.
- Make sure you are using the latest release.
- Include your package version, operating system, Python version, and hardware (CPU or GPU, and CUDA version if relevant).
- For numerical problems, include a minimal example, the result you expected, and the reference you are comparing against.

## Response times

Community support is provided on a best-effort basis by the maintainers and the community. There is no guaranteed response time. Supported commercial deployments are handled separately through ZenteiQ.
